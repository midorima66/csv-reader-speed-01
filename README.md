A fast drop-in replacement for csv-reader 1.0.0: a slice-based parser that returns exactly the reference program's answer {columns, rows, errors} for every input — including broken CSV, stray CRs, and unterminated quotes — several times faster.

## Run it

```sh
node main.ts
```

The driver reads every case from /input/cases.json and writes the answers to /output/answers.json (outside a container, MAKEFUN_INPUT_DIR and MAKEFUN_OUTPUT_DIR stand in for /input and /output).
